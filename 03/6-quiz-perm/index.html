    22. III.6 Questions d'auto-évaluation – Permissions

    1. Créez un répertoire nommé emptydir, puis affichez les droits d’accès propres à ce répertoire (sans lister son contenu).

      Réponse

      L’option -d (directory) de la commande ls permet d'afficher les métadonnées et permissions du répertoire lui-même au lieu de son contenu :

      $ mkdir emptydir 
$ ls -ld emptydir
drwxr-xr-x 2 alice alice 4096 Feb 10 12:00 emptydir

    2. Créez un fichier vide nommé emptyfile. En utilisant chmod en mode symbolique, ajoutez les droits d’exécution pour le propriétaire, et retirez les droits d’écriture et d’exécution pour le groupe et les autres, le tout en une seule commande.

      Réponse

      Décomposition des actions : - Pour le propriétaire (u) : ajouter l'exécution $\rightarrow$ u+x - Pour le groupe et les autres (go) : retirer l'écriture et l'exécution $\rightarrow$ go-wx

      On sépare ces deux actions par une virgule :

      $ touch emptyfile
$ chmod u+x,go-wx emptyfile

    3. Quels seront les droits d’accès par défaut attribués à un nouveau fichier si le masque umask est fixé à 027 ?

      Réponse

      La permission maximale de départ pour un fichier ordinaire étant 666 (rw-rw-rw-) : $$666 - 027 = 640 \rightarrow \mathbf{-rw-r-----}$$ Le propriétaire a les droits de lecture et écriture (rw-), le groupe a la lecture seule (r--), et les autres utilisateurs n'ont aucun accès (---).

    4. Considérons un script shell nommé test.sh avec les droits suivants :

      -rwxr-sr-x 1 carol root 33 Dec 11 10:36 test.sh

      Quels sont les droits du propriétaire du fichier ?

      Réponse

      Les droits du propriétaire (caractères 2 à 4) sont rwx : lecture, écriture et exécution. Le bit SGID (s) présent sur le groupe n'affecte pas les droits directs du propriétaire.

    5. En utilisant la notation octale, quelle commande chmod permet de retirer les droits spéciaux (SUID/SGID) de ce fichier tout en conservant ses permissions classiques ?

      Réponse

      En utilisant une notation à 4 chiffres avec un premier chiffre nul (0) :

      $ chmod 0755 test.sh
# ou en mode symbolique :
$ chmod g-s test.sh

    6. Examinez le périphérique suivant :

      $ ls -l /dev/sdb1
brw-rw---- 1 root disk 8, 17 Dec 21 18:51 /dev/sdb1
      De quel type de fichier s'agit-il et qui possède les droits d'écriture ?
      Réponse

      Le premier caractère b indique un fichier spécial en mode bloc (block device), représentant une partition de disque. Seuls le superutilisateur root (propriétaire) et les utilisateurs membres du groupe système disk possèdent les droits de lecture et d’écriture (rw-).

    7. Considérons les quatre entrées suivantes :

      drwxr-xr-t 2 carol carol 4,0K Dec 20 18:46 Another_Directory
----r--r-- 1 carol carol    0 Dec 11 10:55 foo.bar
-rw-rw-r-- 1 carol carol 1,2G Dec 20 18:22 HugeFile.zip
drwxr-sr-x 2 carol users 4,0K Jan 18 17:26 Sample_Directory

      Donnez la valeur numérique octale correspondante sur 4 chiffres pour chacune :

      Réponse
      • Another_Directory : 1755 (1 pour le Sticky Bit, 755 pour rwxr-xr-x).
      • foo.bar : 0044 (aucun bit spécial 0, aucun droit propriétaire 0, lecture groupe 4, lecture autres 4).
      • HugeFile.zip : 0664 (aucun bit spécial 0, lecture/écriture 6 pour propriétaire et groupe, lecture 4 pour autres).
      • Sample_Directory : 2755 (2 pour le bit SGID, 755 pour rwxr-xr-x).

    8. Que se passe-t-il si vous exécutez chmod 4 emptyfile puis chmod 44 emptyfile ?

      Réponse

      En mode octal, chmod applique les chiffres de droite à gauche (du moins significatif au plus significatif) :

      • chmod 4 emptyfile équivaut à chmod 0004 emptyfile : seuls les autres (others) reçoivent le droit de lecture (-------r--).
      • chmod 44 emptyfile équivaut à chmod 0044 emptyfile : le groupe et les autres reçoivent la lecture (----r--r--).

      Pour définir les droits de manière prévisible, il est fortement recommandé de toujours spécifier 3 chiffres (ex. 644) ou 4 chiffres (ex. 0644).

    9. Pourquoi le Sticky Bit est-il configuré sur le répertoire /tmp ?

      $ ls -ld /tmp
drwxrwxrwt 19 root root 16K Dec 21 18:58 /tmp
      Réponse

      Le répertoire /tmp est accessible en écriture à tous (world-writable, droits 777). Sans le Sticky Bit (t), n'importe quel utilisateur malintentionné pourrait supprimer ou écraser les fichiers temporaires créés par d'autres utilisateurs ou par les démons système.

      Le Sticky Bit garantit que seul le propriétaire d'un fichier (ou root) a le droit de le supprimer ou de le renommer.

    10. Un fichier possède les permissions -rwSr-xr-x. Que signifie la lettre S majuscule ?

      Réponse

      La présence d'un S majuscule signifie que le bit SUID est activé, mais que le droit d'exécution sous-jacent pour le propriétaire (u+x) est manquant.

      • s minuscule = bit spécial actif avec droit d'exécution (x).
      • S majuscule = bit spécial actif sans droit d'exécution (souvent le signe d'une mauvaise configuration).

    11. Comment configurer un répertoire collaboratif Box où les nouveaux fichiers appartiennent automatiquement au groupe users, avec interdiction pour les membres de supprimer les fichiers créés par leurs collègues ?

      Réponse

      Il faut combiner le bit SGID (pour l'héritage du groupe) et le Sticky Bit (pour la protection contre la suppression par autrui) :

      $ mkdir Box
$ sudo chown :users Box
$ chmod 3770 Box
# ou en notation symbolique :
$ chmod g+rwxs,o+t Box

      Le premier chiffre octal 3 est la somme de SGID (2) et Sticky Bit (1). Les droits résultants sont :

      $ ls -ld Box
drwxrws--t 2 carol users 4096 Jan 18 19:09 Box
