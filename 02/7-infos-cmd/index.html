    14. II.7 Obtenir des informations sur les commandes

    Ci-dessous une sélection de commandes indispensables pour identifier la nature d'une commande, localiser ses fichiers exécutables ou consulter sa documentation intégrée :

    • 14.1 II.7.1 man : Affiche la page de manuel d'une commande ou d'un fichier de configuration.
    • 14.2 II.7.2 apropos : Recherche des commandes par mots-clés dans les descriptions du manuel.
    • 14.3 II.7.3 type : Indique comment le shell interprète une commande (programme binaire, primitive interne, alias).
    • 14.4 II.7.4 file : Détermine le format et le type exact d’un fichier.
    • 14.5 II.7.5 which : Localise l’exécutable associé à une commande dans les répertoires du $PATH.
    • 14.6 II.7.6 whereis : Localise les binaires, les sources et les pages de manuel associées.
    • 14.7 II.7.7 locate : Recherche rapidement des fichiers via une base de données indexée.
    • 14.8 II.7.8 history : Affiche l’historique des commandes saisies dans la session.

    14.1 II.7.1 man

    La commande man (manual) permet de consulter la documentation officielle du système. La syntaxe est man [section] nom_commande.

    $ man ls
LS(1)                            User Commands                           LS(1)
NAME
       ls - list directory contents
DESCRIPTION
       List  information  about the FILEs (the current directory by default).  Sort entries
       alphabetically if none of -cftuvSUX nor --sort is specified.  Always  show  hidden  files  (those  starting with .) except when -a   or -A is specified.

    Les sections du manuel

    Le manuel Linux est découpé en plusieurs sections numérotées. Les plus courantes sont : - Section 1 : Commandes utilisateur exécutables (ls, cp, passwd). - Section 5 : Formats des fichiers de configuration (/etc/passwd, /etc/fstab). - Section 8 : Commandes d'administration système (fdisk, useradd, systemctl).

    Exemple : man 1 passwd affiche l'aide sur la commande pour changer de mot de passe, tandis que man 5 passwd documente la structure du fichier /etc/passwd.

    14.2 II.7.2 apropos

    La commande man requiert de connaître le nom exact de la commande. Si vous cherchez une commande par sa fonction, utilisez apropos (ou man -k), qui effectue une recherche textuelle dans la ligne de résumé de toutes les pages de manuel.

    Par exemple, pour rechercher les commandes en rapport avec le noyau (kernel) :

    $ apropos kernel
systemd-udevd-kernel.socket (8) - Device event managing daemon
uname (2)            - get name and information about current kernel
urandom (4)          - kernel random number source devices

    14.3 II.7.3 type

    La commande type permet d’identifier la manière dont le shell exécutera une commande donnée (sans avoir à ouvrir le manuel). Elle indique s’il s’agit d'une commande interne (shell builtin), d’un programme externe situé dans le système, d’un alias ou d’une fonction shell :

    $ type uname cp kill which
uname is hashed (/bin/uname)
cp is /bin/cp
kill is a shell builtin
which is /usr/bin/which

    L'option -a permet d'afficher toutes les définitions disponibles pour un même nom :

    $ type -a echo
echo is a shell builtin
echo is /bin/echo

    14.4 II.7.4 file

    La commande file analyse la signature binaire (les nombres magiques) d'un fichier pour déterminer son type réel, indépendamment de son extension :

    $ file /bin/ls
/bin/ls: ELF 64-bit LSB executable, x86-64, version 1 (SYSV), dynamically linked, interpreter /lib64/ld-linux-x86-64.so.2, for GNU/Linux 3.2.0, BuildID[sha1]=0x123456789abcdef, stripped

    Cette commande identifie avec précision les binaires compilés (ELF), les scripts shell (ASCII text executable), les fichiers compressés, les images ou les données brutes.

    14.5 II.7.5 which

    La commande which parcourt les répertoires listés dans la variable $PATH de gauche à droite et retourne le chemin complet du premier exécutable correspondant :

    $ which ls
/bin/ls

    14.6 II.7.6 whereis

    La commande whereis recherche simultanément l'emplacement de l'exécutable binaire, de ses fichiers sources et de ses pages de manuel dans les dossiers standards du système :

    $ whereis ls
ls: /bin/ls /usr/share/man/man1/ls.1.gz

    14.7 II.7.7 locate

    La commande locate effectue une recherche quasi instantanée dans l'ensemble de l'arborescence en interrogeant une base de données d'indexation locale (mlocate ou plocate) :

    $ locate ls
/bin/ls
/usr/bin/ls
/usr/share/man/man1/ls.1.gz

    Mise à jour de l'index

    Les fichiers récemment créés ou supprimés n’apparaîtront qu'après la mise à jour de la base d'indexation. Pour forcer l'actualisation manuelle, exécutez la commande avec les privilèges administrateur : 

    $ sudo updatedb

    14.8 II.7.8 history

    La commande history affiche la liste numérotée des commandes précédemment saisies dans la session de shell :

    $ history
1  ls
2  cd /home/frank
3  echo $PATH
4  export PATH=$PATH:/home/frank/bin    
5  history

    14.8.1 II.7.8.1 Raccourcis indispensables de l'historique

    • !n : réexécute la commande numéro n (ex: !3 réexécute la commande 3).
    • !! : réexécute la dernière commande exécutée (très utile avec sudo !! pour relancer la commande précédente avec les droits d'administration).
    • !chaine : réexécute la dernière commande commençant par chaine.
    • Ctrl + R : lance la recherche incrémentale inversée dans l'historique au fur et à mesure de votre saisie.
